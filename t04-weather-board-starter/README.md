# WEATHER LOG — T04 실시간 기상 정보판 (초기 구현)

공개 기상 API Open-Meteo로 대전 현재 기온을 조회하고, 값·단위·출처·원천 관측 시각·조회 시각·KST를 표시합니다. 정상 조회를 KST 날짜별로 upsert하고, 실패 시 localStorage의 마지막 정상값을 보존합니다. 공식 합성 9개 fixture를 별도 공간에서 재생할 수 있습니다.

## 실행
로컬 테스트는 HTTP 서버가 필요합니다: `python -m http.server 8000` 후 `http://localhost:8000`.

## 중요한 미완료 항목
이 버전은 배포 전 작업본입니다. 실제 영구 데이터는 브라우저 localStorage에만 저장되어 기기 간 공유되지 않습니다. 정식 제출에는 공유 서버 저장소, 두 실제 날짜의 기록, 과제 플랫폼이 봉인하는 `t04_day` 영수증 정확히 2건, 공개 배포 및 비로그인 접속 검증이 별도로 필요합니다. fixture 기록은 해당 조건을 대체하지 않습니다. 다른 날의 기록은 절대 합성하거나 위조하면 안 됩니다.

## 구조
`index.html` 화면, `app.js` 조회·기록·재생, `assets/fixtures` 공식 합성 입력, `assets/*.json` 공개 계약과 판정 기준.
